# ShopHub – E-Commerce SQL Analytics Project

## Project Overview
This project focuses on analyzing an e-commerce dataset using MySQL.
It covers database design, data cleaning, data quality validation, and business analysis.

## Tools & Technologies
- MySQL
- MySQL Workbench
- SQL

## Project Progress
- Database schema creation
- Data cleaning and validation
- Entity Relationship Diagram (ERD)
- Data Dictionary
- Data Quality Report

## Repository Structure
- sql/ – SQL scripts
- documentation/ – ERD, Data Dictionary, and Data Quality Report
- screenshots/ – Project execution evidence (to be added)

## Dataset
Brazilian E-Commerce Public Dataset by Olist.
